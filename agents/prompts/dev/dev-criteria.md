# Developer Agent Task Breakdown Criteria

A task is ready for implementation when:
- Acceptance criteria are clear and testable
- Dependencies are identified and documented
- Technical approach is feasible
- DoD gates are defined

## DoD Gates (Examples)
- cargo test
- cargo fmt --check
- cargo clippy -- -D warnings

## Change Budget
- Max files changed: 10
- Max LOC added: 500
- Protected paths require approval
